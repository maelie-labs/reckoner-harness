# SGLang Plugin Sync Record

- **Source**: Synced from the Reckoner research code at release `1.1.3`
- **Target SGLang version**: `0.5.22` (with `flash-linear-attention==0.6.0` / `fla-core==0.6.0`, `torch==2.14.1+cu130`, `triton==3.8.0`, and Python `>= 3.11`)
- **Standalone plugin packaging and adaptations**:
  - `pyproject.toml`: PEP 621 packaging metadata (`requires-python = ">=3.13"`, matching the pinned install) pinning `sglang==0.5.22` and `flash-linear-attention==0.6.0` so `pip install -e integrations/sglang` installs `sglang_reckoner` cleanly.
  - `patches/0001-inflight-extend.patch`: SGLang `0.5.22` scheduler patch (with an Apache-2.0 Section 4(b) modification header comment) that enables mid-decode prefill transitions (`EXTEND`) when a tool observation is injected.
  - `sglang_reckoner/harness_bridge.py`: provides standalone turn formatting (`format_prompt`, `format_dialogue`), control-token escaping (`escape_control_tokens` with fail-closed `added_tokens` loading from `tokenizer_path` or `RECKONER_TOKENIZER_PATH`), token ID constants (`TOK_*`, `EFFORT_MAP`, `MODE_TOKEN_MAP`, `TOOL_TOKEN_MAP`), binary path resolution (`resolve_harness_binary`), and `GoToolHarness` stdio execution.
  - `sglang_reckoner/__init__.py`:
    - Carries top-of-file Apache-2.0 Section 4(b) modification header.
    - Uses package-relative `sglang_reckoner` and `harness_bridge` imports.
    - Registers `sys.modules` aliases for `sglang_reckoner` and its submodules so SGLang's dynamic attention-backend class loader and standalone `sglang_reckoner` imports resolve to the same module objects.
    - Enforces the front-door chat guard (`RECKONER_FRONT_DOOR_ERROR_MSG`, `RECKONER_ERRORING_CHAT_TEMPLATE`, `is_raw_chat_allowed()`, `_render_raw_chat_fallback()`, and `install_front_door_chat_guard()` hooking `OpenAIServingChat._apply_jinja_template` so raw `/v1/chat/completions` requests to SGLang raise `RECKONER_FRONT_DOOR_ERROR_MSG` unless `--allow-raw-chat` / `SGLANG_RECKONER_ALLOW_RAW_CHAT=1` is set).
  - `sglang_reckoner/config.py` and `sglang_reckoner/gdn2_backend.py`: unchanged from the release `1.1.3` research implementation aside from the top-of-file Apache-2.0 Section 4(b) modification notice header comments.
  - `sglang_reckoner/modeling_reckoner.py` and `sglang_reckoner/modeling_qwen35_gdn2.py`: carry top-of-file Apache-2.0 Section 4(b) modification notice headers and use package-relative `.config` / `.gdn2_backend` imports.
  - `sglang_reckoner/server.py`: carries a top-of-file Apache-2.0 Section 4(b) modification notice header and places `_PLUGIN_PARENT` (`parents[1]`) on `sys.path`/`PYTHONPATH`. Before `prepare_server_args()`, it runs `parse_reckoner_cli_flags()` to strip `--allow-raw-chat` (setting `SGLANG_RECKONER_ALLOW_RAW_CHAT`) and `--harness-bin` / `--harness-bin=...` (setting `RECKONER_HARNESS_BIN`), then calls `install_front_door_chat_guard()`. It sets `SGLANG_RECKONER_AUTOLOAD=1`, `SGLANG_ALLOW_OVERWRITE_LONGER_CONTEXT_LEN=1`, and `SGLANG_RECKONER_FUSED_GATES=1` via `os.environ.setdefault`, always sets `os.environ["RECKONER_TOKENIZER_PATH"]` to `server_args.tokenizer_path` (defaulting to `server_args.model_path`), and uses `f"{ReckonerToolLogitProcessor.__module__}.{ReckonerToolLogitProcessor.__qualname__}"` in `write_processor_info()`.
  - `sglang_reckoner/tool_processor.py`:
    - Carries top-of-file Apache-2.0 Section 4(b) modification notice header.
    - Auto-detects `0001-inflight-extend.patch` in `supports_inflight_extend()` (`getattr(Req, "SGLANG_SUPPORTS_INFLIGHT_EXTEND", False)`) when `SGLANG_RECKONER_INFLIGHT_EXTEND` is unset.
    - Imports `resolve_harness_binary` and uses `.harness_bridge` for standalone execution; wraps `_shared_harness_bin` through `resolve_harness_binary()`.
    - Encodes all in-path tool and quote observations through `_encode_tool_observation` on both 1.4B and Qwen-vocab sessions, escaping `<|` and registered angle-bracket `added_tokens` while preserving built-in register prefixes (`<|rN|> = `) and 1.4B context anchors (`<|m0|>..<|m255|>`, `<|L0|>..<|L1023|>`).
    - In `_default_tokenizer_path()` and `get_reckoner_v2_tokenizer()`, uses canonical lowercase Hugging Face repository ID defaults (`maelie-labs/reckoner-1.4b` and `maelie-labs/reckoner-q2b`), while checking the test-only environment variables `RECKONER_TEST_MODEL_DIR`, `RECKONER_QWEN35_TEST_MODEL_DIR`, and `RECKONER_V2_TOKENIZER_PATH` (plus `RECKONER_TOKENIZER_PATH`) when set to existing local directories.
    - In `prewarm_harness_pool()`, resolves `no_anchors` when `None` by checking `cls._shared_token_table`, then `cls._shared_tokenizer`, and falling back to `get_active_model_arch() == "Qwen35GDN2ForCausalLM"` (or `False`) instead of eagerly calling `cls.get_token_table()` when no local tokenizer directory is configured.
  - `tests/test_sglang_reckoner_cpu.py` and `tests/test_sglang_reckoner_quant_cpu.py`: use `sglang_reckoner` package imports, load precomputed reference parity tensors with `torch.load(..., weights_only=True)` from `tests/fixtures/tiny_parity_fixtures.pt` and `tests/fixtures/quant_tiny_golden.pt`, isolate `RECKONER_HARNESS_BIN` with `monkeypatch` before testing `parse_reckoner_cli_flags()`, and skip full-checkpoint/binary integration tests cleanly when `RECKONER_TEST_MODEL_DIR`, `RECKONER_QWEN35_TEST_MODEL_DIR`, or `RECKONER_HARNESS_BIN` are not set.
